## 3. 전처리 과정

### 3.1 본문 추출
```
원본 URL 시도 → 실패 시 네이버 URL → 실패 시 description 사용
```
- 추출 성공률: 99.7%
- 품질 검사: 제목-본문 토큰 30% 이상 일치 확인

### 3.2 키워드 매칭 (진단항목 분류)
- `keyword.xlsx`의 23개 진단항목 × 5개 키워드 = 115개 키워드
- 매칭 방식: 본문에서 키워드 포함 여부 확인
- 매칭률: 42.3% (32,887건 중 13,913건)

**매칭 예시**:
```
기사: "서울대가 탄소중립 실현을 위해 온실가스 배출량을 30% 감축..."
→ 키워드 "탄소중립", "온실가스" 매칭
→ 진단항목: "탄소배출량" (E)
```

## 4. 점수 계산 방법론

### 4.1 기본 공식
```
점수 = (기사 수 × 매체 가중치 × 감성 가중치) / 최댓값 × 5
```

### 4.2 매체 가중치
| 그룹 | 예시 | 가중치 |
|------|------|--------|
| major | 조선일보, KBS, JTBC | 1.0 |
| economic | 매일경제, 에너지경제 | 0.8 |
| regional | 경인일보, 더팩트 | 0.5 |
| internal | 국민대신문 | 0.3 |
| unknown | 미분류 | 0.4 |

### 4.3 감성 분석
| 감성 | 키워드 예시 | 값 | 가중치 |
|------|------------|-----|--------|
| 긍정 | 선정, 달성, 우수, 혁신 | +1 | ×1.3 (Y축) |
| 부정 | 미흡, 지적, 논란, 사고 | -1 | ×1.5 (X축) |
| 중립 | 기타 | 0 | ×1.0 |

## 5. 계산 예시: "취약계층 지원강화"

### 5.1 X축 (이슈 노출도) 계산

**산업 리스크 데이터에서 매칭된 기사: 2,312건**

| 단계 | 계산 |
|------|------|
| 1. 기사별 노출도 | 매체 가중치 (평균 0.55) |
| 2. 감성 분석 | 긍정 312건, 중립 1,850건, 부정 150건 |
| 3. 가중치 적용 | 부정 기사 ×1.5 |
| 4. 합계 | 1,271.5 (weighted_exposure) |
| 5. 정규화 | 1,271.5 / 1,691.7 × 5 = **3.76** |

### 5.2 Y축 (영향 중대성) 계산

**국민대 미디어 데이터에서 매칭된 기사: 420건**

| 단계 | 계산 |
|------|------|
| 1. 기사별 노출도 | 매체 가중치 (평균 0.63) |
| 2. 감성 분석 | 긍정 98건, 중립 310건, 부정 12건 |
| 3. 가중치 적용 | 긍정 기사 ×1.3 |
| 4. 합계 | 265.3 (weighted_exposure) |
| 5. 정규화 | 265.3 / 265.3 × 5 = **5.00** (최댓값) |

### 5.3 최종 위치
- **X축**: 3.76 (Q1 영역, >2.5)
- **Y축**: 5.00 (Q1 영역, >2.5)
- **사분면**: Q1 (핵심 중대 주제)

## 8. 분석 한계 및 유의사항

1. **키워드 매칭 한계**: 단순 키워드 포함 방식으로, 문맥을 고려하지 않음
2. **감성 분석 정확도**: 규칙 기반 분석으로, 복잡한 뉘앙스 반영 어려움
3. **매체 가중치 주관성**: 가중치 설정에 주관적 판단 포함
4. **시점 차이**: 산업 이슈와 국민대 미디어의 시점이 완전히 일치하지 않을 수 있음
